# 🛍️ Stylerizz Fashion Analytics

An end-to-end **fashion e-commerce & multi-vendor marketplace analytics** platform built as part of the **PH-06 WOLFOX Stylerizz internship task**.

## 🎯 Project Overview

Stylerizz is modeled as a fashion marketplace selling **ethnic and occasion wear**
through both **platform-owned** and **vendor-listed** inventory.

This project delivers:

- **Normalized SQL schema** (42 tables, PKs/FKs/indexes)
- **Synthetic data generator** (~20K rows for portfolio use)
- **Streamlit analytics app** (5 pages: Dashboard, Reports, Analysis, Generate Report, Power BI embed)
- **Deep-dive reports** on products, categories, vendors, payments, coupons, appointments
- **Strategic analysis**: funnel, cohorts, RFM, delays, data quality
- **CSV/Excel export** for 12 preset reports
- **Power BI integration** ready

## 🧱 Tech Stack

| Layer | Tools |
|-------|-------|
| Database | MySQL / MariaDB (via XAMPP or MySQL Community) |
| Python | pandas, mysql-connector-python, plotly |
| Web UI | Streamlit |
| Reporting | CSV, Excel (openpyxl), Power BI |
